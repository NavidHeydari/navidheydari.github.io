## Project Overview

Static portfolio website for Navid Heydari (Principal Architect / AI Architect), deployed via GitHub Pages. A Node.js/TypeScript build step compiles `src/main.ts` to `js/main.js`. All content is in `index.html`; `blogs.html` is a separate page for future blog posts.

## Commands

```bash
npm install          # Install dev dependencies (TypeScript 5.4)
npm run build        # Compile src/main.ts → js/main.js (tsc)
npm run watch        # Watch mode — recompiles on save
npm run dev          # Watch mode + local HTTP server on port 8000
```

Preview locally (without watch):

```bash
python3 -m http.server 8000
```

## Deployment

```bash
./deploy.sh    # Commits and pushes to GitHub Pages (run after npm run build)
```

## Architecture

Single-page portfolio with a separate blog page. **Do not edit `js/main.js` directly** — it is compiled output and is gitignored.

### Key Files

| File | Purpose |
|------|---------|
| `src/main.ts` | TypeScript source for all interactivity (compiled to `js/main.js`) |
| `js/main.js` | Compiled output — gitignored, generated by `npm run build` |
| `index.html` | Main portfolio page: hero, about, skills, experience, education, contact |
| `blogs.html` | Blog listing page (currently empty placeholder) |
| `css/style.css` | All styling: responsive layout, dark/light theme, animations |
| `assets/images/profile_pic.jpg` | Profile photo used in the About section |

### TypeScript Config

- Target: `ES2020`, lib: `ES2020 + DOM`
- Strict mode enabled (`strict`, `noUnusedLocals`, `noUnusedParameters`, `noImplicitReturns`)
- Output: `js/` directory, source root: `src/`

### CSS Theme System

Themes are implemented via a `dark-theme` class toggled on `<body>`. Light theme is the default (no class); dark theme applies when `body.dark-theme` is present. The JS reads/writes `localStorage` key `theme` to persist the user's preference.

### JS Scroll Animations

Elements with `.fade-in` get a `visible` class added by an `IntersectionObserver` when they enter the viewport. Child elements (`.skill-item`, `.project-card`, `.timeline-item`) animate in with staggered delays.

### Hamburger Menu

On mobile (≤768px), the nav collapses behind a hamburger button (`#hamburgerMenu`). The nav gets a `menu-open` class when open. Closing is handled by: link click, Escape key, focus-out, click outside, and window resize above 768px.

### Smooth Scrolling

All `<a href="#...">` links use `preventDefault` and `window.scrollTo` with `behavior: 'smooth'`, offset by the fixed nav height. Links pointing to external pages (e.g., `blogs.html`) are unaffected.

### Responsive Breakpoints

Mobile-first. Main breakpoints in `style.css`:

| Breakpoint | Behavior |
|------------|----------|
| ≥1920px | Extra large — wider max-widths, larger headings |
| ≥1440px | Large desktop adjustments |
| ≤1024px | Tablet portrait / small desktop |
| ≤900px | Tablet landscape — reduced nav gap |
| ≤768px | Mobile — hamburger nav, stacked layouts |
| ≤480px | Small mobile — further size reductions |
| `hover: none, pointer: coarse` | Touch device — disables hover transforms |
